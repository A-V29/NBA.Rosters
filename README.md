How to play: Download a file and in [basketball-gm](https://basketball-gm.com/) select New league >> Custom and Upload league file. Or can copy & paste file URL(click the preferred file in this folder and click raw, then copy the URL address) in game select New league >> Custom and Enter league file URL, paste copied URL there.

NBA Roster files for basketball-gm.com, based on alexnoob's NBA Rosters (https://github.com/alexnoob/BasketBall-GM-Rosters).

Contains all regular season and playoff stats(Stats are from https://www.basketball-reference.com). Adjusted 2026 draft, complete 2027-2029 drafts. 

Base version is like alexnoob's NBA roster file.

Balanced version changes some players age a year older(to the real  birthyear, like they are in the game's built-in rosters), salary caps are set higher to avoid players signing for too low amount of money, injury rate increased

Summerleague is with real roster and schedule
